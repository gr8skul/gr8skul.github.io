### One thing to watch when testing I would **not test this first with a real designation that is attached to important works**. Add something disposable, for example: text Mood: TEST MOOD Type: TEST TYPE Put `TEST TYPE` on one test work through the already-working upload page. Then delete `TEST TYPE` from Taxonomy Manager. We should see: text Taxonomy Manager ↓ DELETE TEST TYPE ↓ delete-taxonomy ↓ track-metadata.json ↓ TEST TYPE removed from the work ↓ catalog regenerated **Do not press SAVE TAXONOMY after deleting the test type.** The deletion function itself saves that deletion. The SAVE button remains for your normal add/reorder workflow. One caveat: your deployed Edge Function currently has CORS allowing `https://gr8skul.com`. If you access the manager at `www.gr8skul.com`, the browser may reject the request. If your manager is at `gr8skul.com`, we're good for this test.
